# Folio

Folio is a Chrome (Manifest V3) browser extension prototype. It saves web pages and text selections into a personal, local "folio" with notes and tags, and lets you browse, search and export what you saved.

Status: prototype under construction, Foreman order WO-20261030-002. The scope is a working assumption made at the owner's request on 2026-10-29. The original Cursor cloud agent spec was not recoverable.
